# archive/nes — the NES port's documents

Archived on 2026-10-31 when the `gbc-port` branch started. These are kept for reference only and are not required reading.

- `HANDOFF.md`, `PROGRESS.md`, `PORTING_PLAN.md`, `BUGS&FEATS.md`: the NES project's status, history, roadmap and bug list.
- `AGENTS.md`, `PROJECT_README.md`: the NES rules and the old README.
- `LESSONS.md`, `MESEN_MCP_NOTES.md`, `PERFORMANCE_SUMMARY.md`: NES-specific test, perf and emulator notes.

Paths inside these files refer to the old layout (for example `info/` and `docs/do_not_read_unless_asked/`). Find NES history with `Select-String -Path archive\nes\PROGRESS.md -Pattern 'keyword'`, then read only the matching `### date - title` entry. Full NES tree: `git checkout main`.
