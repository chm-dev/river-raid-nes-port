River art note: a tree is not a sprite or a tile.  It is a template fragment
of `$BC` bytes (4*$BC pixels) by `$BE` scanlines, copied into consecutive row
buffers at a byte offset that can be odd.  The capture's rows 11..32 are a
32-px x 22-row feature (`$BC=8`, offset 4, template `$BD12`); its template
rows 21..0 match the captured rows exactly.  See `docs/ATARI_RE_SPEC.md`
section 6.3.

`src/atari_data.h` holds the arrays behind `ATARI_DATA_IMPL`; the generated
`src/atari_data.c` defines the macro and includes it once.

Atari colour indices in the data refer to `assets/atari/palette_altirra_ntsc.bin`
(NTSC, 256 RGB triplets).
