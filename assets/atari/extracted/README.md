## HUD glyph inventory (`charset.bin`)

`charset.bin` is the runtime 1 KiB character set at `$0600-$09FF`: 128
8x8 1bpp glyphs, addressed as `index = code & 0x7F`, `offset = index * 8`.
The HUD art is already in this file — do **not** redraw it.  The small
labels use the game's compressed 4-pixel font (two letters per glyph);
the gauge and plane icon are single-purpose glyphs.

| Code | Art | Source use / NES use |
|---|---|---|
| `$01-$1A` (`$61-$7A` mirror) | Uppercase A-Z, 6x7 px | `GAME` (`G/A/M/E = $07/$01/$0D/$05`), doubled to 16x8 |
| `$50-$59` | Digits 0-9 | game number, hi-score, score in the normal font |
| `$43` | "BR" in the 4-px font | BRIDGE label (doubled horizontally) |
| `$44` | "ID" | BRIDGE label |
| `$45` | "G" | BRIDGE label |
| `$46` | "E" | BRIDGE label |
| `$47` | gauge top-left + full marker | gauge top row |
| `$48` | gauge top rule | gauge top row (repeated) |
| `$49` | top rule + upper half of 1/2 | gauge top row centre |
| `$4A` | gauge top-right + empty marker | gauge top row |
| `$4B` | gauge bottom-left + E | gauge bottom row |
| `$4C` | gauge bottom rule | gauge bottom row (repeated) |
| `$4D` | bottom rule + lower half of 1/2 | gauge bottom row centre |
| `$4E` | gauge bottom-right + F | gauge bottom row |
| `$5A` | "P1" | player-1 label (doubled) |
| `$5B` | "HI" | high-score label (doubled) |
| `$5C` | plane icon | remaining-lives icons (yellow sprites) |

The gauge is assembled as `47 48 49 48 4A` over `4B 4C 4D 4C 4E`
(5 cells x 16 px = 80 px at mode-6 scale).  E, 1/2 and F are baked into the
gauge glyphs, so the labels never change.  The yellow fuel bar is not in the
charset: it is a 10-px-tall, 4-px-wide sprite that starts just below the top
markers and slides from the F marker (full) to the E marker (empty), behind
the fixed labels.  Place its sprite X on the marker X (the art occupies
tile columns 0..3).  The original HUD buffer (`hud_runtime.bin`) uses the
high-bit forms `$C7..$CE`; masking with `$7F` gives the glyph codes above.
